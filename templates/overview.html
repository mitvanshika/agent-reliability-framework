Did my AI agent get worse after I changed something?

The framework runs a fixed set of test questions through the old and the new version of a system, scores every answer with a panel of LLM judges, and uses paired statistics (McNemar, Wilcoxon) to say whether the change made it worse, better, or no real difference, and which questions moved and why.

Scroll for the story, told with one real experiment. Dotted words have a plain-English explanation: hover or tap them.

Why trust the verdict?

A test is only useful if it stays quiet when nothing changed, and if its judges are fair. Both were checked on real runs.

{% if tr.aa %}

Same setup twice: {{ tr.aa.got }}

The {{ tip("baseline") }} configuration was run a second time with nothing changed. The framework correctly found no real difference: {{ tr.aa.detail }}. A/A write-up →

{% endif %} {% if tr.noise %}

Judges are noisy: same answer, {{ "%g"|format(tr.noise.a|float) }} vs {{ "%g"|format(tr.noise.b|float) }}

In those two identical runs, {{ tr.noise.scenario_id }}'s answer was word for word the same, yet the {{ tr.noise.judge }} judge scored it {{ "%g"|format(tr.noise.a|float) }} and then {{ "%g"|format(tr.noise.b|float) }}. That's why single scores aren't trusted: the framework uses {{ tip("noise band", "noise bands") }} and paired tests instead.
