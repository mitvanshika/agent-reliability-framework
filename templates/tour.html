Explain: why test a system like this at all?

When you change an AI system (its prompt, model or search settings), nothing crashes: it just quietly gets a bit better or worse. This framework answers, for each change: did it get better or worse, on which questions, why, is it real or just chance, and what did it cost?

Explain: what are these steps?

Each line is one thing the system did while answering, recorded by the framework: a search, a tool call, or an LLM call with its tokens and seconds. The names on the LLM calls are the system's own labels for them. How many steps there are, and in what order, is the system's choice; the framework only records them, so the cost of each question can be traced to the step that spent it.
